# KPIs — what we measure and the targets

Targets are starting points. `/scorecard` rewrites the "Current" column weekly.

| KPI | Definition | Target | Current |
|---|---|---|---|
| 3s retention | % of viewers still watching at 3s | ≥ 75% | |
| 50% retention | % still watching at half runtime | ≥ 45% | |
| Full watch | % who watched to the end | ≥ 25% (short), ≥ 15% (long) | |
| Follows per 1K views | new followers / views × 1000 | ≥ 2.0 | |
| Saves per 1K views | | ≥ 5 | |
| Shares per 1K views | | ≥ 5 | |
| Comments per 1K views | | ≥ 3 | |
| Long videos posted / week | videos ≥ 65s | ≥ 3 | |
| Follower delta / week | | ≥ 600 (10K by end of 2026) | |
| Views / 30 days | rolling | ≥ 100K, maintained | |

## Milestones
- 5,000 followers → leaves affiliate pilot caps (if approved)
- 10,000 followers + 100K views/30d → apply to Creator Rewards
- First month of Creator Rewards → build media kit for brand deals

## What we do not chase
- Raw view count without follows or saves
- Engagement from anything that is not a real person choosing to interact
