# inbox/

Drop raw material here. Agents read this folder; the owner cleans it out.

- Ideas: any `.md` or `.txt`
- Analytics: TikTok CSV exports (`/ingest-analytics`, Phase 4)
- Screenshots: paste the text you can read from them into a `.md` next to the image
- Comment threads: paste into `comments-YYYY-MM-DD.md`
- Intake answers: `intake-answers.md` (read by `/intake`)

Files here are not edited by agents.
